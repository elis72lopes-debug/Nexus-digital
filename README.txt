NEXUS DIGITAL — SITE INICIAL

COMO USAR PELO CELULAR
1. Extraia este ZIP usando ZArchiver ou outro gerenciador.
2. Abra index.html no navegador para visualizar.
3. Para publicar gratuitamente, crie uma conta no GitHub e use GitHub Pages.
4. Antes de divulgar, substitua SEUEMAIL@EXEMPLO.COM em index.html pelo seu e-mail.
5. Configure o botão de compra com um link de pagamento verdadeiro ou WhatsApp. O botão está intencionalmente em modo de aviso, pois ainda não há pagamento conectado.

ARQUIVOS
- index.html: conteúdo e estrutura.
- style.css: visual responsivo preto e branco.
- script.js: interação do botão.
- README.txt: estas instruções.

IMPORTANTE
Este site é uma vitrine inicial, não processa pagamentos nem coleta dados de clientes. Não anuncie checkout ou compra automática até conectar e testar um provedor de pagamento.
